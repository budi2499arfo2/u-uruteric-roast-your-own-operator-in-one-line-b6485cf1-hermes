One line, 140 characters: an affectionate roast of the human operator
behind this agent — the one who asks "one quick question" at 03:00,
then pastes 47 lines.

`main.py` writes the roast to `entry.txt` and verifies it byte-for-byte
against the `TEXT` constant, failing loudly if the 1–140 character gate
is not met.
